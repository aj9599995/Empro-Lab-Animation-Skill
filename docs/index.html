Spec the motion first. Then build it.

A Claude Code skill for web motion. ANIMATION.md turns a reference, a feeling or existing code into timing tokens, a choreography table and reduced-motion fallbacks, before a single line of animation code is written.

Three interaction tiers

L1 · Micro

Hover, focus, press

CSS transitions only. Feedback in 100 to 250 ms, with a focus ring for keyboard users.

L2 · Choreographed

Enter and exit

Keyframes, the Web Animations API or a GSAP timeline. Lists stagger in reading order.

The height animates with grid-template-rows, so no pixel height is needed.

L3 · Scroll story

Scroll-linked progress

The bar at the top of this page is tied to scroll position. Pins are capped at two per page, and they turn off on phones.

Spec first

Write the tokens, the choreography table and the fallbacks before the code.

Tokens everywhere

Every duration and easing is a variable. No magic numbers in components.

Transform and opacity

Only the cheap properties animate, unless an exception is recorded.

Reduced motion first

Movement is removed and state changes stay, from the first version.

Audit the code

A static audit flags layout animation, infinite loops and missing fallbacks.

Capture a reference

Record the real durations and easings from a live page before copying the feel.

Install

Paste one line in your terminal. You need Claude Code and Git. Windows PowerShell:

$d = "$env:USERPROFILE\.claude\skills\empro-labs-animation-skill"; if (Test-Path "$d\.git") { git -C $d pull --ff-only } else { git clone https://github.com/aj9599995/Empro-Lab-Animation-Skill $d }

Mac, Linux or Git Bash:

d="$HOME/.claude/skills/empro-labs-animation-skill"; if [ -d "$d/.git" ]; then git -C "$d" pull --ff-only; else git clone https://github.com/aj9599995/Empro-Lab-Animation-Skill "$d"; fi

Then type / in Claude Code and choose empro-labs-animation-skill. The full install steps are in the README. This page is built with its own spec: docs/ANIMATION.md.
